How to use this widget:

This is a standalone widget bundle that can be embedded in any website. The widget appears as a floating bubble without affecting your page styling.

Features:

  • Floating chat bubble with rolling animation
  • Two-step registration (name + email/phone)
  • Conversation history management
  • Real-time chat with AI assistant
  • Session persistence with MongoDB backend

Backend API: http://localhost:3000/api
